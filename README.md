# Image Tower Online

Two-player online physics stacking game.

## Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/htmt1/image-tower-online)

The repository includes `render.yaml` configured for a free Render web service.

After deployment, open the generated `onrender.com` URL on both devices. One player creates a room and the other joins using the six-digit room code.

## Local test

```bash
npm install
npm start
```

Then open `http://localhost:3000`.
